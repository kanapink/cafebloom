# Café Bloom

自然素材にこだわるカフェを想定して制作した、ポートフォリオ用のランディングページです。

## コンセプト

植物や木の温もりを感じる、落ち着いたカフェの雰囲気を表現しました。
メニューや店舗情報を、スマートフォンからも見やすく紹介しています。

## 使用技術

- HTML
- CSS
- JavaScript

## 主な内容

- カフェのコンセプト紹介
- メニュー紹介
- 店舗情報・アクセス
- スマートフォン対応のナビゲーション

## ファイル構成

- `index.html`：ページの内容
- `style.css`：デザインとレイアウト
- `script.js`：メニューなどの動き
- `images/`：ページで使用する画像
